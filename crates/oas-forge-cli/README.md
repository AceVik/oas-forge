# oas-forge-cli

Command-line interface of [`oas-forge`](https://crates.io/crates/oas-forge):
generate OpenAPI documents from annotated Rust source code.

```bash
cargo install oas-forge-cli
oas-forge -i src -o openapi.yaml
```

See the [oas-forge documentation](https://github.com/AceVik/oas-forge) for the
annotation syntax and all options.
